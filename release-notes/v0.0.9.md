# Release v0.0.9

## Highlights

### Resource loading & live updates

- **Background resource cache**: Deployments, pods, secrets, configmaps, services and Helm releases now load once per connected cluster and stay live in the background. Switching tabs is a pure re-render with no reload, no watch restart and no flicker.
- **Namespace switching is instant**: Core kinds are watched cluster-wide and filtered in the app, so changing namespaces no longer restarts any watch. If you lack cluster-wide access, Lumen falls back to per-namespace watching automatically.
- **Connection status banners**: When a watch is reconnecting, errored or forbidden, a banner explains why while the rows already loaded stay visible.
- **Resync on focus and wake**: Lumen refreshes its watches when the window regains focus or the machine wakes from sleep.
- **Helm releases from secrets**: Releases are derived from the existing secrets stream, so no extra connections or permissions are needed.

### Crossplane

- **New Crossplane section**: A read-only sidebar group that appears only when Crossplane is detected in the cluster. It has five views: Overview, Packages, Definitions, Composites and Managed resources.
- **Crossplane detail drawer**: Health banner, per-category sections and reference links between related resources.
- **Claim → XR → managed resource graph**: Visualize how a claim maps through its composite to the managed resources behind it, as a graph or a list.
- Works with Crossplane v1.20 and v2.x (including namespaced composites).

### Deployment Full View

- **Full-page deployment view**: Open any deployment from its drawer with the new **Full View** button for a 12-section overview in one place, covering rollout state, revision history, pod distribution, containers, config and storage references, networking, labels and selectors, and a security posture summary.
- **Revision diff**: Compare pod-template changes between revisions.
- **Live refresh**: The view updates as the deployment changes, with secret values never fetched or displayed.

### Clusters & kubeconfig

- **Rename a cluster context**: Right-click a cluster in the list and choose **Rename**. Lumen updates the kubeconfig (including `current-context`), pinned clusters, open tabs, watchers and terminals.
- **New contexts appear without a restart**: Contexts added to your kubeconfig while Lumen is running show up automatically. A removed active context is handled gracefully.
- **Custom kubeconfig path is honored**: The kubeconfig path in Settings is now used for cluster access, falling back to the default when it is empty or missing.

### Nodes

- **Architecture distribution chart**: A new donut chart on the Nodes page shows ARM vs non-ARM vs unknown nodes, keeping the raw `arm64` / `amd64` labels. It follows the current search filter.
- **Table always reachable**: Fixed the Nodes table being hidden or clipped when Stats was expanded or the window was short. The page now scrolls to the table, which keeps its sticky header and virtualized rows and resizes with the window.

### Bottom panel & terminals

- **Unsaved YAML edits are kept**: Edits now persist per tab across tab switches, log or terminal detours, pop-out and server refreshes. Closing a tab with unsaved changes asks for confirmation.
- **Context-bound terminals**: Each terminal is bound to the cluster context it was opened with, shown in the tab subtitle, a toolbar badge and a banner line.
- **Multiple terminals**: Open several independent, closable terminal tabs with the **+** button or Cmd+Shift+`. Scrollback survives tab switches.
- **Cordon/drain target the right cluster**: These actions now pass an explicit `--context` instead of switching your global kubectl context.
- **Cleaner session cleanup**: Terminals are shut down when the window closes or the app quits.

## Fixes

- YAML tabs are now scoped per cluster, fixing a case where a tab could save to the wrong cluster.
- Fixed listener leaks in the preload bridge: event subscriptions now remove only their own listener.
- Fixed multi-namespace selection loading inconsistent data.
- Fixed stale generic watchers leaking after a cluster switch.
- Removed the legacy per-event watch channels, which cut IPC volume and stops raw Kubernetes objects from reaching the UI.

## Under the hood

- Electron updated to 42.x (`fix:pty` now targets 42.2.0).
- Added a bundled Apache-2.0 license notice for code adapted from crossview.
- Large new test suite covering the resource cache, Crossplane, deployment details and rename flow.
- No new runtime dependencies.

## ⚠️ Notes

- Watching core kinds cluster-wide keeps every pod, deployment, secret, configmap and service for the cluster in memory (trimmed). Very large clusters may notice higher memory use.
- A shell rc file that exports `KUBECONFIG` can override a terminal's context binding. Check the context shown in the terminal badge against `kubectl config current-context` if in doubt.
- Cordon/drain from a local terminal now use `--context` rather than changing your global kubectl context.

Lumen remains in active development; please report issues on our GitHub repository.
