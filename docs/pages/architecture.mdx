# Architecture

Lumen is built on Electron with a clear separation between the main process and the renderer process.

## Main Process

The main process handles all system-level operations:

- **Kubernetes API** — All cluster communication via `@kubernetes/client-node`
- **AWS SDK** — EC2, EKS, STS, CloudTrail, and Bedrock clients
- **Terminal** — PTY management via `node-pty`
- **AI** — Prompt execution and streaming via Vercel AI SDK
- **Storage** — Persistent settings via `electron-store`

## Renderer Process

The renderer is a React application that handles UI only:

- **State Management** — Hoisted state in App.tsx, passed via props
- **Real-time Updates** — Kubernetes watchers with batched updates (650ms debounce)
- **Virtualized Lists** — `react-virtualized` for large resource lists
- **Animations** — Framer Motion for smooth transitions

## IPC Communication

All communication between processes goes through the preload bridge:

- **Renderer → Main** — Async calls via `window.k8s.*` API
- **Main → Renderer** — Event emitters for streaming data (logs, watchers, AI)
