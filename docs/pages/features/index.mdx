# Features Overview

Lumen provides a comprehensive set of tools for Kubernetes cluster management, all accessible from a single desktop application.

## Core Features

| Feature | Description |
|---|---|
| [AI Assistant](/features/ai-assistant) | Natural language explanations of Kubernetes resources |
| [Cluster Management](/features/cluster-management) | Multi-cluster switching, pinning, and namespace filtering |
| [Resource Monitoring](/features/resource-monitoring) | Real-time views for workloads, networking, storage, and config |
| [Log Viewer](/features/log-viewer) | Multi-tab log streaming with container selection |
| [Integrated Terminal](/features/terminal) | Built-in terminal with PTY support |
| [YAML Editor](/features/yaml-editor) | Monaco-based editor with diff view |
| [Port Forwarding](/features/port-forwarding) | One-click port forwarding for services and pods |
| [Resource Topology](/features/topology) | Visual resource relationship graphs |

## Design Philosophy

Lumen is built with a dark-mode-first glassmorphism aesthetic. Every surface uses transparency and blur to create depth, giving the UI a modern, polished feel that's easy on the eyes during long sessions.
