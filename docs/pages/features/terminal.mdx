# Integrated Terminal

Lumen includes a built-in terminal powered by XTerm.js and node-pty for full PTY support.

## Features

- **Full PTY emulation** — Supports interactive commands, tab completion, and color output
- **Resizable panel** — Drag to resize the terminal panel
- **Multiple sessions** — Open multiple terminal tabs
- **Configurable font size** — Adjust in Settings

## Usage

Open the terminal from the bottom panel. It launches your default shell with your environment variables intact, including any AWS credentials from Granted.

## Configuration

| Setting | Default | Description |
|---|---|---|
| Font Size | 13 | Terminal font size in pixels |

Configure in **Settings → General**.
