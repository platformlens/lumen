# Port Forwarding

Lumen provides one-click port forwarding for pods and services.

## Features

- **Simple setup** — Select local and remote ports via a modal dialog
- **Active session tracking** — View all active port forwards in the status bar
- **Auto-cleanup** — Port forwards are stopped when you disconnect from a cluster

## Usage

1. Select a pod or service
2. Click **Port Forward** in the detail drawer or resource actions
3. Configure the local port and target port
4. Click **Start** to begin forwarding

## Managing Active Forwards

Active port forwards are displayed in the bottom status bar. Click to view details or stop individual forwards.
