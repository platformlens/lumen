# Lumen

A modern, high-performance Kubernetes management tool built as an Electron desktop application.

Lumen provides a sleek, intuitive interface for monitoring and managing Kubernetes clusters with a focus on developer experience and visual clarity.

## Key Highlights

- **Real-time Monitoring** — Live updates for Pods, Nodes, Deployments, and other Kubernetes resources
- **Multi-Cluster Support** — Seamless switching between different Kubernetes contexts with pinned cluster shortcuts
- **Integrated Tools** — Built-in log viewer, terminal, port forwarding, and YAML editor
- **AI Assistant** — Integrated AI panel for explaining Kubernetes resources
- **Visual Topology** — Resource relationship visualization and pod visualizer
- **Modern UI** — Dark-mode first design with glassmorphism aesthetics

## Who is Lumen for?

DevOps engineers, platform engineers, and developers who need a powerful desktop tool for managing Kubernetes clusters with better UX than kubectl and web-based dashboards.

## Platform Support

Currently focused on macOS (arm64), with planned support for Windows and Linux.
